# 🚐 Fleetly

**Sistema de gestión de flotas de vehículos y trabajadores.**

Fleetly es un proyecto de desarrollo de software orientado a la gestión y administración de flotas de vehículos. Su objetivo es centralizar la información de los vehículos y trabajadores de una empresa mediante un sistema compuesto por un ERP web y una aplicación móvil.

El proyecto se desarrolla como Trabajo de Fin de Grado del ciclo formativo de **Desarrollo de Aplicaciones Multiplataforma (DAM)**.

## 🎯 Objetivo del proyecto

Facilitar la gestión diaria de una empresa con vehículos y trabajadores, mejorando la organización, el seguimiento de las operaciones y la comunicación entre los empleados y la persona responsable de la flota.

## ✨ Funcionalidades principales

### 💻 ERP web

- **Gestión de vehículos:** administración de la información de la flota.
- **Gestión de trabajadores:** organización y administración de los empleados.
- **Control centralizado:** acceso a la información relevante para la gestión de la empresa.
- **Integración con la aplicación móvil:** conexión entre el sistema de administración y los trabajadores.

### 📱 Aplicación móvil

- **Autenticación:** acceso de los trabajadores mediante inicio de sesión.
- **Control horario:** registro de la jornada laboral.
- **Estado del vehículo:** comunicación diaria del estado y la ubicación del vehículo.
- **Gestión de incidencias:** notificación de problemas o averías relacionados con los vehículos.
- **Registro de repostajes:** anotación de los repostajes realizados.

Fleetly se organiza en dos módulos principales:


La solución está diseñada para conectar la gestión administrativa de la flota con las operaciones diarias de los trabajadores.

## 🚀 Instalación y ejecución

Para ejecutar el proyecto, consulta las instrucciones y los requisitos específicos de cada módulo:

1. Clona el repositorio.
2. Accede a la carpeta `ERP` o `Android`, según el componente que quieras ejecutar.
3. Configura las dependencias y los servicios necesarios.
4. Sigue las instrucciones de ejecución correspondientes a cada módulo.

```bash
git clone https://github.com/narcisaducovschi/Fleetly.git
cd Fleetly
```

> **Nota:** Los requisitos adicionales y los pasos de configuración deben completarse según el entorno de desarrollo de cada módulo.
